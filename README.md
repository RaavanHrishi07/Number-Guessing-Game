# Number Guessing Game

A simple and interactive number guessing game built with Python and Tkinter. It features a dark-themed GUI, multiple difficulty levels, helpful hints, and an attempt counter.

## Features

- **Interactive GUI:** Clean, dark-themed interface built with Tkinter.
- **Multiple Difficulty Levels:** Choose a difficulty level to change the guessing range.
- **Helpful Hints:** Find out whether your guess is too high or too low.
- **Attempt Counter:** Keep track of your valid guesses.
- **Play Again:** Start a new round after winning.
- **Input Validation:** Handles empty inputs, non-integer values, and out-of-range guesses.
- **Unit Tests:** Includes automated tests using pytest.

## Technologies Used

- Python 3
- Tkinter
- Pytest

## Getting Started

### Prerequisites

- Python 3.11 or a compatible Python 3 version
- pip

### Installation

Clone the repository:

```bash
git clone https://github.com/RaavanHrishi07/Number-Guessing-Game.git
cd Number-Guessing-Game
```

Install the testing dependency:

```bash
python -m pip install pytest
```

### Run the Game

```bash
python main.py
```

### Run Tests

```bash
python -m pytest -v
```
